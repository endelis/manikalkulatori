### Kas ir CSS peldēšanā?

CSS jeb kritiskais peldēšanas ātrums rāda teorētisko tempu, ko peldētājs var uzturēt ilgstoši bez pārmērīgas piena skābes uzkrāšanās. Tas kalpo par pamatu treniņu tempu noteikšanai.

### Kā izmērīt CSS?

Visbiežāk lietotais tests ir 400 metru un 200 metru peldējums ar maksimālu piepūli, katra posma laiku mērot atsevišķi. CSS aprēķina no laika starpības starp abiem peldējumiem.

### Kāpēc CSS ir noderīgs treniņu plānošanā?

Zinot CSS, var precīzi noteikt intervālu tempu dažādiem treniņu mērķiem, piemēram, izturības vai ātruma attīstīšanai. Tas ir vienkāršāk izmērāms nekā laktāta slieksnis, taču sniedz līdzīgi noderīgu atskaites punktu.
